# Example outputs

Reference examples for the requirements skill, drawn from the Northshore Outdoor Living sample project. They show structure, level of detail and tone. Read them before writing your first outline or requirement in a session.

- `clarification-agenda.md`: Phase 1 output, open questions sorted into blocking, Hero can answer, and can wait.
- `solution-outline.md`: Phase 2 output, the outline shown in chat for steering.
- `requirements.md`: three requirements, including one with a module and one without.
- `decision.md`: a Design Decision where guidance overrides a client suggestion.

These are examples, not records. They live in the skill folder and are never validated or indexed.

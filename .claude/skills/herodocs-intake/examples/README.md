# Example digests

Reference examples for the intake skill, drawn from the Northshore Outdoor Living sample project. They show the expected structure, level of detail, attribution and tone.

- `meeting-digest.md`: a meeting digest. Note how needs stay in business language, suggestions go under Proposed approaches without judgment, and gaps become Open questions.
- `guidance-digest.md`: a guidance digest. Note the Direction section with the reasoning for each point, and how it explicitly addresses a client suggestion it overrides.

These are examples, not records. They live in the skill folder and are never validated or indexed.
